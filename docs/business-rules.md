# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额。
- 已收金额只合计未被冲正的收款；一笔收款被冲正后，其金额从已收金额中扣减。已收与未收金额之和始终等于订单金额。
- 冲正以（租户, 订单标识, 冲正标识）幂等：同一冲正标识重复请求且指向同一收款时按首次结果重放，不重复扣减；同一冲正标识指向另一笔收款时必须拒绝（冲正标识冲突）。
- 冲正只能点名存在且属于该订单（租户）的收款；收款已被冲正后不得再次冲正。业务拒绝须给出可区分原因，不得与内部错误混为一谈；被拒绝时订单与收款状态保持不变。
- 冲正只影响被点名的那一笔收款，同订单其他收款不变；冲正成功后订单可继续登记收款，再次收满时状态回到已结算。
- 跨租户读取或冲正一律按“不存在”处理，不得泄漏对象是否存在。
- 收款与冲正按订单串行生效（数据库事务）：并发下已收金额不超过订单金额且不为负，失败不得留下半笔生效记录。
- 金额以最小货币单位的整数表示，不使用浮点数。
