# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额 + 已退金额；收款不得超过未收金额。
- 退款按笔登记，每笔必须携带调用方提供的退款标识；退款标识以（租户, 退款标识）唯一，同一订单重复提交不重复扣减并返回首次结果，同租户不同订单复用标识必须被拒绝。
- 单笔退款不得超过当前可退净额：可退净额 = 已收金额 − 已退金额；超出时整笔登记被拒绝，订单各金额均不变化。
- 退款成功后退回款项重新计入未收金额，可再次收款；无论收款、退款、再收款如何交错，恒有：订单金额 = 已收金额 − 已退金额 + 未收金额，且各计数不为负。
- 登记过程原子完成：并发竞争同一可退空间时只有一笔成功，其余按超出可退净额拒绝。
- 跨租户读取或登记一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。
- 批量导入以（租户, 批次标识）幂等：同标识同内容重复提交返回与首次一致的结果且不重复受理；同标识不同内容必须拒绝。导入逐行校验、部分成功，单行不合法或与既有订单重复只拒绝该行且不改动既有订单；每行结果（含失败行的行号与原因）原子落库，服务中断后按批次标识续跑，已生效行不重复受理，终态恒有：成功行数 + 失败行数 = 提交总行数。
- 条件检索严格限定在调用方租户内，支持按订单标识前缀、订单状态、已收金额下限任意组合过滤，按订单标识升序分页；相同条件下分页稳定、不重不漏。每页条数由调用方指定且有上限，超出按上限返回；游标只在同租户、同过滤条件且未过期时有效，非法、跨租户、换条件、过期的游标分别以可区分的原因拒绝。
- 结算按笔发起，每笔必须携带调用方提供的结算标识；结算标识以（租户, 结算标识）唯一，同一订单同一金额重复提交返回与首次一致的结果，同标识用于不同订单或不同金额必须被拒绝。订单未收金额大于 0 时整笔拒绝，不产生任何账务或状态变化；结算金额须等于订单应收金额。结算成功后订单进入已结算状态，结算记录留存结算金额与结算时点的已收、已退金额。
- 冲正按笔发起，每笔必须携带调用方提供的冲正标识；冲正标识与结算标识是两个独立请求身份，各自以（租户, 标识）唯一、互不复用去重。冲正作废订单当前生效的结算记录、订单退回未结算状态，冲正记录留存原因文本；同一冲正标识重复提交返回与首次一致的结果，对同一结算重复冲正必须被拒绝。冲正后可重新结算，同一订单任一时刻至多一条生效结算记录，历史结算与冲正记录保留可查。
- 订单账务历史按（时间, 业务标识）升序列出收款、退款、结算、冲正条目，每条含业务标识、类型、金额与操作后未收金额；重放同一序列得到与当前一致的最终未收金额与状态。
- 对账按租户发起，对账标识以（租户, 对账标识）唯一；生成时将该租户全部订单的汇总与逐单快照原子落库：订单笔数、应收合计、已收合计、已退合计、未收合计及每张订单是否存在生效结算。守恒：应收 = 已收 − 已退 + 未收（未收沿用现有定义，含退款回冲部分），逐张订单金额与订单读取接口一致。同一对账标识重复发起返回与首次一致的结果、不重复计算；对账期间新发生的账务不改变已生成结果，换新标识重新发起才反映。
- 结算、冲正、收款、退款在同一订单任意交错不得重复扣减、重复加回或出现状态金额不一致；一次请求要么整体生效要么整体不生效，失败不留半截记录；已完成的结算、冲正与对账结果重启后仍可查询，重复提交不产生新的账务效果。
