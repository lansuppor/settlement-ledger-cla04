# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额 + 已退金额；收款不得超过未收金额。
- 退款按笔登记，单笔不得超过当前可退净额（已收金额 − 已退金额）；超出时拒绝且账面不变。
- 退款标识在租户内唯一：同一订单重复提交同一标识不重复扣减，返回首次登记的结果；不同订单复用同一标识必须被拒绝。
- 退款成功后退回金额重新回到未收金额，可再次收款；任意操作序列下始终保持 订单金额 = 已收金额 − 已退金额 + 未收金额，各计数不为负。
- 跨租户读取一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。
