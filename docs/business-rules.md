# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额 + 已退金额；收款不得超过未收金额。
- 退款按笔登记，每笔必须携带调用方提供的退款标识；退款标识以（租户, 退款标识）唯一，同一订单重复提交不重复扣减并返回首次结果，同租户不同订单复用标识必须被拒绝。
- 单笔退款不得超过当前可退净额：可退净额 = 已收金额 − 已退金额；超出时整笔登记被拒绝，订单各金额均不变化。
- 退款成功后退回款项重新计入未收金额，可再次收款；无论收款、退款、再收款如何交错，恒有：订单金额 = 已收金额 − 已退金额 + 未收金额，且各计数不为负。
- 登记过程原子完成：并发竞争同一可退空间时只有一笔成功，其余按超出可退净额拒绝。
- 跨租户读取或登记一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。
- 批量导入逐行校验、部分成功：每行沿用受理订单的全部规则（租户+订单标识唯一、金额为正整数、币种限于允许集合）；单行不合法或与库内已有订单重复只拒绝该行，不影响同批其它行，且不修改已被重复拒绝的既有订单。
- 批次标识由调用方提供，同一租户内唯一；重复提交同一批次标识且内容一致时不重复受理、不重复扣减，返回与首次完全一致的受理回执；内容不一致必须被拒绝。
- 批量导入为异步受理：每行结果（成功/失败及原因、行号）与批次计数原子落库；服务中断重启后续跑同一批次，已生效行不重复受理，未完成的行继续处理；恒有 成功行数 + 失败行数 = 提交总行数，各计数不为负。
- 条件检索严格限定在调用方租户内，跨租户订单永不出现；过滤条件（订单标识前缀、订单状态、已收金额下限）可任意组合，未提供表示不限制；结果按订单标识升序分页，相同条件下不重不漏。
- 检索游标仅在同租户、同过滤条件下有效；过期与跨租户（或条件不符、无法识别）的游标必须以可区分的失败原因拒绝。
