# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额 + 已退金额；收款不得超过未收金额。
- 退款按笔登记，每笔必须携带调用方提供的退款标识；退款标识以（租户, 退款标识）唯一，同一订单重复提交不重复扣减并返回首次结果，同租户不同订单复用标识必须被拒绝。
- 单笔退款不得超过当前可退净额：可退净额 = 已收金额 − 已退金额；超出时整笔登记被拒绝，订单各金额均不变化。
- 退款成功后退回款项重新计入未收金额，可再次收款；无论收款、退款、再收款如何交错，恒有：订单金额 = 已收金额 − 已退金额 + 未收金额，且各计数不为负。
- 登记过程原子完成：并发竞争同一可退空间时只有一笔成功，其余按超出可退净额拒绝。
- 跨租户读取或登记一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。
- 批量导入以（租户, 批次标识）幂等：同标识同内容重复提交返回与首次一致的结果且不重复受理；同标识不同内容必须拒绝。导入逐行校验、部分成功，单行不合法或与既有订单重复只拒绝该行且不改动既有订单；每行结果（含失败行的行号与原因）原子落库，服务中断后按批次标识续跑，已生效行不重复受理，终态恒有：成功行数 + 失败行数 = 提交总行数。
- 条件检索严格限定在调用方租户内，支持按订单标识前缀、订单状态、已收金额下限任意组合过滤，按订单标识升序分页；相同条件下分页稳定、不重不漏。每页条数由调用方指定且有上限，超出按上限返回；游标只在同租户、同过滤条件且未过期时有效，非法、跨租户、换条件、过期的游标分别以可区分的原因拒绝。
- 结算以（租户, 结算标识）幂等：结算标识由调用方提供。订单未收金额大于 0 时拒绝结算，不产生任何结算记录、账务历史或状态变化；成功后订单进入已结算状态并生成结算记录，记录结算金额与结算时的已收、已退金额。同一结算标识对同一订单、同一金额重复提交返回与首次一致的结果；同一标识用于不同订单或不同金额拒绝；订单不存在或跨租户按不存在处理。同一订单任一时刻至多一条生效结算记录；冲正后可重新结算，结算代数（seq）递增，历史记录保留可查。
- 冲正以（租户, 冲正标识）幂等：冲正标识由调用方提供，与结算标识是两个独立请求身份，可同名，互不复用或去重。冲正成功后对应结算记录作废、订单退回未结算状态，冲正记录留存原因文本与冲正后未收快照。同一冲正标识重复提交返回与首次一致的结果；对同一结算重复冲正拒绝；结算不存在、不属于该订单或跨租户按不存在处理。
- 订单存在生效结算期间账务已闭合：此时未收为 0，收款本就因超过未收被拒；退款（会回冲未收并使订单退回未结算）也必须先冲正结算，以免出现生效结算仍在而订单未结清的不一致状态。仅凭全额收款进入已结清状态而无生效结算记录的历史订单不受此限。
- 订单账务历史按时间与业务标识升序列出收款、退款、结算、冲正条目，每条含业务标识、类型、金额与操作后未收金额；该序列可解释某时点订单为何处于当前状态，重放同一序列得到与订单读取接口一致的最终未收金额与状态。
- 对账以（租户, 对账标识）幂等：对账标识由调用方提供。对账在单个事务内取该租户全部订单的一致性快照，汇总订单笔数、应收合计、已收合计、已退合计、未收合计，并逐订单记录金额与当前是否存在生效结算。守恒关系：应收 = 已收 + 未收，其中未收沿用“订单金额 − 已收 + 已退”口径（含退款回冲部分），故应收 = Σ(订单金额 + 已退)；逐订单金额与订单读取接口一致。同一对账标识重复发起返回与首次一致的汇总，不重复计算；对账期间新发生的账务不改变已生成结果，重新以新标识发起才反映；跨租户查询按不存在处理。
- 结算、冲正、收款、退款均在单个 IMMEDIATE 事务内读取校验并写订单、记录与账务历史，一次请求要么整体生效要么整体不生效，失败不留半截记录；同一订单任意交错并发下不重复扣减、不重复加回，状态与金额保持一致。所有记录随事务落库，重启后已完成的结算、冲正与对账结果仍可查询，重复提交不产生新的账务效果。
